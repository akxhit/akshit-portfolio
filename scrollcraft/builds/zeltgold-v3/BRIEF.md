# Zelt Gold v3
Self-authored under explicit creative delegation: user requested a complete typography, spacing, layout, elements and animation revamp using current assets.

## Eight decisions
- Vibe: editorial, assured, tactile, precise (authored).
- Journey: proposition → delivery context → customer decisions → operational responsibility → launch touchpoints → reflection (authored from existing content).
- Energy: sculptural opening, quiet context, interactive peak, evidence, warm close.
- Feeling: curiosity → confidence → understanding → reassurance → completeness → reflection.
- Signature: customer-to-counter journey. Selecting a customer decision reveals its paired jeweller or platform responsibility and actual screenshot. Pairings are design explanations, not claims of a live integration.
- Range: editorial with bold typography and restrained motion.
- Structure: distinct chapters, natural flow. No scroll hijacking or empty pinned duration.
- Assets: existing screenshots, live website captures and hero reel only. No generated imagery.

## Grammar and gate
Editorial dossier with an interactive evidence desk. Not a one-shot film, worldflight, or continuous gallery: this is a hiring-review case study, so readable evidence and user-controlled detail lead. Fixed slim chapter navigation, layered phone hero, varied editorial / working-surface / browser-proof / reflection sequence, concluding design principles.
Differs from hero-v2 in all six dimensions (grammar, nav, hero, sequence, close, signature). Gallery-footer is an iteration of that prior site.
