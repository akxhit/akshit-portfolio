# ZELTGOLD UX Case Study

Standalone Next.js source for the ZELTGOLD product design case study.

## Contents

- `app/`: case study narrative, metadata, responsive design system, and global styles
- `components/`: device frames, Motion reveals, GSAP and Lenis providers, Three.js and ThreeUI scenes, plus shadcn and Kokonut UI interactions
- `public/media/`: selected high-quality app screens, launch-site captures, and the product-flow reel
- `research/`: video analysis, high-quality screenshots, contact sheets, and the detailed UX audit

## Stack

- Next.js 16 and React 19
- Tailwind CSS 4
- GSAP and Lenis
- Motion
- Three.js and DesignCode ThreeUI
- shadcn primitives and Kokonut UI interaction patterns

Run `npm run dev` for local development and `npm run build` to export the case study. The main portfolio imports the exported build into `/work/zeltgold`.
